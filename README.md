# 한글 파일 열기 (simple-hwp)

한글 프로그램이 없어도 **`.hwp` 와 `.hwpx` 를 둘 다** 엽니다. **설치할 것이 없습니다.**

👉 **https://60aimake.github.io/simple-hwp/**

## 무엇이 되나

| | |
|---|---|
| **보이는 그대로** | 문서 **첫 장**을 그림으로 보여줍니다. 서식도 그림도 그대로입니다 |
| **글자만** | 글자를 전부 뽑아 줍니다. 복사하거나 `.txt` 로 저장합니다 |
| **사진으로 저장** | 첫 장을 `.png` 로 받습니다 |

## 안 되는 것

- **고치기는 안 됩니다.** 보고 복사하는 것까지입니다
- 그림은 **첫 장만** 나옵니다 (글자는 전부 나옵니다)
- **암호가 걸린 문서**는 글자를 못 뽑습니다. 보이는 그대로만 나옵니다

## 안전

**파일이 기기 밖으로 나가지 않습니다.** 서버로 아무것도 보내지 않습니다.
브라우저 안에서만 풀어서 보여 줍니다.

## 속 — 바깥 라이브러리 0개

HTML 한 장입니다. 브라우저가 이미 가진 기능만 씁니다.

| 형식 | 속 | 꺼내는 곳 |
|---|---|---|
| `.hwpx` | ZIP + XML | 글자 `Contents/section*.xml` 의 `<hp:t>` · 그림 `Preview/PrvImage.png` |
| `.hwp` | OLE2 복합문서 | 글자 `BodyText/Section*` (raw deflate → 레코드 67) · 그림 `PrvImage` |

압축은 `DecompressionStream('deflate-raw')` 로 풉니다.
